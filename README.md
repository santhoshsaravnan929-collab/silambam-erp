# Silambam ERP — Local Mobile Edition

This is a standalone installable PWA designed for one Android phone. Data is stored locally in IndexedDB and the app works offline. WhatsApp sending requires internet.

## Install on Android
1. Host this folder from any HTTPS/static host or use a local HTTPS server. PWAs generally require HTTPS (localhost is an exception).
2. Open index.html/site in Chrome.
3. Use Add to Home Screen / Install App.

## Backup
Use Reports or the top 💾 button to export a JSON backup. Store it safely (Google Drive/USB/email). Restore it from Reports.

## Important
This edition is single-device local-first. Multiple phones do not share data automatically. For multi-device synchronization, use a cloud backend later.
